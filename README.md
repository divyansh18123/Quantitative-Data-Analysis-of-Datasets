# Quantitative Data Analysis of Datasets

This project focuses on performing exploratory data analysis (EDA) on structured datasets provided in CSV format using Python. The objective is to extract meaningful insights through statistical analysis and visualizations.

## Key Features
- Data cleaning and preprocessing using Pandas
- Numerical computations and statistical analysis using NumPy
- Data visualization using Matplotlib
- Generated visual insights through:
  - Histograms  
  - Box plots  
  - Distribution plots  
  - Summary statistics  

## Outcomes
- Identified trends, outliers, and distribution patterns  
- Derived actionable insights from real-world datasets  
- Strengthened understanding of data-driven decision making
